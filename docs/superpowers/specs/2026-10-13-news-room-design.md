# 뉴스방 리디자인 설계

## 목표

기존 저장함 페이지(흰 바탕 목록)를 "오스카의 뉴스방"으로 바꾼다. 개발자 느낌(어두운 바탕 + 터미널 초록)과 아늑한 픽셀 감성(밤 도시 배너, 고양이)을 섞은 반응형 페이지. 탭 3개: 📚 저장함, 🗞 지난 다이제스트, 👍 좋아요.

확정 시안: 스크래치패드 `design/v2.html` + `cat.js` + `cats/*.png` (사용자가 Aside에서 확인하고 승인).

## 화면

- **테마**: 한 가지 다크 테마. 바탕 `#0b0e0d`, 강조 터미널 초록 `#4ade80`(선택된 탭·커서에 은은한 빛). 주황 사용 안 함.
- **글꼴**: 제목·탭·라벨은 픽셀 글꼴 Galmuri11/GalmuriMono11, 기사 제목·요약은 Pretendard. 둘 다 jsdelivr CDN.
- **배너**: 저해상도 캔버스로 그린 서울 밤 풍경(별, 달, 남산타워, 초록 불빛 창문, 창턱, 화분). 시간대별 4종 — 06~16시 낮, 16~19시 노을(보라), 그 외 밤, 비 오는 날은 비. 비 여부는 브라우저가 Open-Meteo(서울 좌표, 키 불필요)에서 현재 날씨를 받아 결정. 실패하면 시간대 그대로.
- **배너 글자**: "오스카의 뉴스방"(이름은 데이터에서, 없으면 "나의 뉴스방"), 시간대 인사, `저장 N · 좋아요 N · 다음 편지 오늘/내일 08:00`, 시계.
- **탭**: PC(폭 760px 초과)는 왼쪽 사이드 탭 + 아래에 고양이 상태 상자, 휴대폰은 화면 아래 고정 탭바. 탭 아이콘은 픽셀 그림.
- **목록**
  - 저장함: 날짜 구분 없이 최신순, 칸마다 제목·한줄요약·`출처 · M/D`.
  - 좋아요: 날짜별 구분선 + 카드 격자(PC 2열).
  - 지난 다이제스트: 날짜별 접는 상자(최신 날짜만 펼침), 취향 밖 기사는 `🎲 취향 밖` 표시.
  - 칸은 작게(여백 10/14px, 제목 15px).
- **화면 전환**: PC는 탭 바꿀 때 픽셀 블록이 덮었다 걷힘, 휴대폰은 옆으로 밀림. 카드는 차례로 올라오며 등장. 배너 날씨 바뀔 때도 픽셀 블록 전환.
- **고양이**: AI로 만든 픽셀 고양이 6마리(구름·짜장·턱시·삼순이·샴푸·두부), 마리당 자세 4장(sleep/sit/walkA/walkB). 날짜로 하루 한 마리 고정.
  - 평소엔 배너 창턱에서 잠.
  - PC: 커서를 따라와서 커서 옆에 앉고, 5초 지나면 그 자리에서 잠. 마우스가 창 밖으로 나가면 창턱으로 돌아감.
  - 휴대폰: 혼자 화면을 산책(가끔 창턱으로 귀가), 빈 곳을 톡 치면 달려옴.
  - 고양이를 누르면 하트 + 이름.
  - "따라오기 끄기"는 localStorage에 기억.
  - `prefers-reduced-motion`이면 창턱에서 잠만 잠.
- **미리보기**: 주소 뒤에 `?preview`를 붙이면 아래쪽에 시간대·고양이 바꾸는 버튼이 나옴(확인용). 평소엔 숨김.

## 데이터 (사람별, 서버에서 만들어 페이지에 박아 넣음)

페이지마다 아래 JSON 하나를 `<script type="application/json" id="data">`에 넣는다.

```json
{"name": "오스카", "saved": [...], "liked": [...], "digests": [{"date": "2026-10-12", "items": [...]}]}
```

기사 항목은 `{title, link, one, source, ts, wild}`. 값이 없으면 빈 문자열/생략.

- **이름**: 본인(`TELEGRAM_CHAT_ID`) 페이지만 `.env`의 `SITE_NAME`(예: 오스카) → "오스카의 뉴스방". 다른 구독자와 `SITE_NAME`이 없을 때는 빈 값 → "나의 뉴스방", 인사도 이름 없이. 구독자별 이름은 이번 범위 밖.
- **saved**: ratings.jsonl의 `bookmark` 중 그 사람 것(기존과 같음).
- **liked**: ratings.jsonl의 `good` 중 그 사람 것. 같은 기사에 👍 뒤 👎를 눌렀으면 마지막 것만 따짐(`_rating_key`와 같은 규칙). `chat` 없는 옛 기록은 본인(`TELEGRAM_CHAT_ID`) 것(`preference_block`과 같은 규칙).
- **digests**: sent-log.jsonl에서 `chat`이 그 사람인 줄, 날짜별 묶음, 최근 30일, 같은 날 같은 기사는 한 번만.
  - 지금 sent-log에는 누구에게 보냈는지(`chat`)가 없음. 그래서 이번에 sent-log 줄에 `chat`, `source`, `wild`를 추가하고, 지난 다이제스트 탭은 다음 발송부터 채워짐(그 전엔 빈 화면 안내 문구).
- **보충**: 한줄요약·출처가 비어 있는 saved/liked 항목은 sent-log에서 같은 제목 해시(`title_hash`)로 찾아 채운다.
- **링크**: http(s)만 넣고 나머지는 빈 문자열(페이지에서도 한 번 더 검사).

## 구조

- 새 폴더 `web/` (저장소에 포함)
  - `web/room.html`: 페이지 틀. `__DATA__` 자리에 JSON이 들어감.
  - `web/cat.js`: 고양이 목록·오늘의 고양이·탭 아이콘.
  - `web/cats/<id>-<pose>.png` 24장.
- `digest.py`
  - `site_pages()`: 사람별 `u/<token>/index.html`은 `room.html`에 그 사람 JSON을 넣어 만든다. `assets/cat.js`, `assets/cats/*.png`도 결과에 포함한다. 그래서 디자인 파일이 바뀌어도 해시가 달라져 재업로드됨.
  - `page_html`·`render_page`: 사람별 페이지에선 안 씀. 루트 안내 페이지(`index.html`)만 새 테마의 짧은 HTML로.
  - `site_hash`/`build_site`: 그림 파일(bytes)도 다루게.
  - 발송 루프: sent-log 줄에 `chat`, `source`, `wild` 추가.
  - 텔레그램 헤더 버튼 이름: "📚 내 저장함" → "🏠 내 뉴스방"(주소는 그대로).
- 배포: 기존 `publish()` 그대로(wrangler pages deploy). 실서비스 반영은 코드 머지 후 `~/news-digest`에 `digest.py`와 `web/` 복사 + 데몬 재시작.

## 보안

- JSON을 `<script>` 안에 넣을 때 `<`를 `<`로 바꿔 `</script>`로 태그를 탈출하지 못하게 함.
- 페이지는 모든 글자를 `textContent`로 넣음(HTML 해석 없음). 링크는 http(s)만, `rel="noopener noreferrer"`.
- `noindex`, `no-referrer` 유지. 비밀 주소 구조(`/u/<token>/`) 그대로.
- 날씨 요청은 서울 고정 좌표만 보냄(개인정보 없음).

## 테스트 (test_digest.py, 기존 방식)

1. 사람별 페이지 JSON: A의 저장·좋아요·다이제스트가 B 페이지에 안 섞임.
2. 좋아요: 👍 뒤 👎면 안 나옴, chat 없는 옛 👍는 본인 페이지에만.
3. 다이제스트: chat 있는 sent-log만, 날짜별 묶음, 30일 넘은 것 제외, 같은 날 중복 제거.
4. 보충: 한줄요약 빈 저장 항목이 sent-log의 `one`으로 채워짐.
5. 탈출 방지: 제목에 `</script><script>alert(1)</script>`가 있어도 페이지에 `</script>`는 진짜 닫는 태그 하나뿐(데이터 부분에 없음). `javascript:` 링크는 빈 문자열.
6. 그림 파일이 site/assets에 써지고, 그림이 바뀌면 해시가 바뀜.
7. 발송 시 sent-log 줄에 chat/source/wild가 기록됨.
8. 기존 테스트 전부 통과(헤더 버튼 문구 테스트는 새 문구로).

브라우저 확인은 Aside로 `--dry` 미리보기(`site/u/<token>/index.html`)를 띄워 PC·휴대폰 폭에서 본다.
